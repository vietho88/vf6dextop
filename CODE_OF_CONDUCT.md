# Code of Conduct

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

Be respectful, technically specific, and constructive. Harassment, personal attacks, discrimination, deliberate disruption, and publication of another person's private information are not accepted.

Maintainers may edit, hide, or remove content and restrict participation when necessary to keep the project productive. Report conduct issues privately to the repository owner through their GitHub profile contact information.
